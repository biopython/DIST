If you are looking for individual Biopython releases, try downloads page or Biopython on PyPI.

This is the Biopython DIST GitHub Repository at github.com/biopython/DIST using GitHub Pages to host biopython.org/DIST/ aka biopython.github.io/DIST/ which (on our original web-server) was a folder of static file for distributing our releases, and associated documentation.

For example, biopython.org/DIST/docs/tutorial/Tutorial-1.83.pdf aka biopython.github.io/DIST/docs/tutorial/Tutorial-1.83.pdf is here under version control at https://github.com/biopython/DIST/blob/gh-pages/docs/tutorial/Tutorial-1.83.pdf - as were older versions of the Tutorial prior to it being produced alongside the API documentation via Sphinx in Biopython 1.84 onwards via https://github.com/biopython/docs/.
